# Headings

Page and section headings. One component with a `level` property, each level bound to its own heading style.

| Level | Style | Size | Face | Weight | Line height | Colour |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | `page-heading` | `font-4xl` (32.4px) | `font-display` | `weight-extrabold` (800) | 1.2 | `text-primary` |
| 2 | `subheading-1` | `font-3xl` (28.8px) | `font-display` | `weight-bold` (700) | 1.2 | `text-primary` |

- One page heading per screen: the screen's title.
- Always "subheading", never "subtitle". `subheading-2` and lower are not defined yet.

Built from tokens only; it contains no other components.
